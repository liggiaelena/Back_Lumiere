## 3. 各資料夾詳細內容與檔案職責 (Directory Details)

### 3.1 `dev/` - 開發主程式與 FastAPI 應用 (Core Application)

`dev/` 目錄是整個 Lumière 後端應用的核心，包含伺服器啟動入口及所有業務邏輯、演算法管線。

#### 3.1.1 頂層檔案
* **[run.py](file:///l:/Lumiere/Back_Lumiere/dev/run.py)**
  * *說明：* 本地啟動入口。使用 Uvicorn 伺服器載入 `dev.app.main:app`，預設執行於 `0.0.0.0:8000` 並啟用 `reload` 自動熱重載。

#### 3.1.2 `dev/app/` - 應用核心模組
* **[main.py](file:///l:/Lumiere/Back_Lumiere/dev/app/main.py)**
  * *說明：* FastAPI 路由與應用初始化。定義 API 端點（如 `/api/analyze` 膚況分析、`/api/analyses/{id}` 歷史查詢）、全域例外處理器，並設定 CORS（跨來源資源共享）允許所有網域請求。
* **[pipeline.py](file:///l:/Lumiere/Back_Lumiere/dev/app/pipeline.py)**
  * *說明：* 核心分析管線協調器。將整個分析流程串接在一起，依次調用影像驗證、臉部定位裁剪、SegFormer 分割、BiSeNet 臉部解析、去病灶膚色提取、OpenAI Vision 區域評估、多模態黑斑確認、產品推薦與醫療警示攔截。
* **[config.py](file:///l:/Lumiere/Back_Lumiere/dev/app/config.py)**
  * *說明：* 基於 `pydantic-settings` 讀取並管理環境變數（如 `.env` 中的金鑰及資料庫路徑），提供強型別的設定值存取。
* **[image_utils.py](file:///l:/Lumiere/Back_Lumiere/dev/app/image_utils.py)**
  * *說明：* 影像處理與品質檢驗。負責二進位圖檔的讀取、旋轉修正 (EXIF 資訊轉向)，並檢驗照片是否過暗 (亮度 < 20)、過曝 (亮度 > 235) 或解析度過低 (< 300px)。
* **[face_detection.py](file:///l:/Lumiere/Back_Lumiere/dev/app/face_detection.py)** 與 **[face_detection_mediapipe.py](file:///l:/Lumiere/Back_Lumiere/dev/app/face_detection_mediapipe.py)**
  * *說明：* 人臉偵測服務。封裝了 MediaPipe 的 BlazeFace 模型，偵測相片中的人臉並計算最大人臉框，向外擴展 35% 進行無失真裁剪 (zoomed face)，作為後續所有分割與分析模型的輸入。
* **[segmentation.py](file:///l:/Lumiere/Back_Lumiere/dev/app/segmentation.py)**
  * *說明：* 管理 SegFormer 雙軌分割模型推理。優先載入 `checkpoints` 中通過指標驗證的獨立專家模型（黑斑、白斑、鮮紅斑痣及皺紋），若無可用專家模型則 Fallback 至舊版 4 分類聯合模型。
* **[face_parsing_bisenet.py](file:///l:/Lumiere/Back_Lumiere/dev/app/face_parsing_bisenet.py)**
  * *說明：* 載入 BiSeNet 19 分類臉部語意分割模型。將臉部細分為額頭、左頰、右頰、鼻子、下巴 5 大分區，並生成實體分區的 mask 與去雜訊遮罩圖。
* **[skin_tone_analyzer.py](file:///l:/Lumiere/Back_Lumiere/dev/app/skin_tone_analyzer.py)**
  * *說明：* 載入 BiSeNet 14 分類膚色分析模型。利用「皮膚類別 mask」並排除「SegFormer 檢測出的病灶與皺紋區域」，精準提取出「去病灶健康膚色」的中位數 (Median) RGB / HEX。
* **[color_analyzer.py](file:///l:/Lumiere/Back_Lumiere/dev/app/color_analyzer.py)**
  * *說明：* 計算上述 5 大臉部區域的去病灶健康膚色，提供精細的分區色彩數據。
* **[color_utils.py](file:///l:/Lumiere/Back_Lumiere/dev/app/color_utils.py)**
  * *說明：* 顏色空間轉換與計算工具。利用 ITA (Individual Typology Angle) 角度演算法將 HEX 轉 Lab 空間並對應 Fitzpatrick 膚色級數 (1~6 級)；並提供基於亮度加權的 Luma-Weighted 歐氏距離來評估區域間色差 ($\Delta E$)。
* **[vision.py](file:///l:/Lumiere/Back_Lumiere/dev/app/vision.py)**
  * *說明：* 整合 OpenAI Vision API。並行發送額頭、左頰、右頰、鼻子、下巴 5 個分區的 crop 影像予 OpenAI (優先使用 `gpt-5.6-luna` 或 `gpt-5.6-luna`)，並提供 SegFormer 分割資訊作為背景 context，要求回傳結構化多語系膚質 notes。
* **[recommendations.py](file:///l:/Lumiere/Back_Lumiere/dev/app/recommendations.py)**
  * *說明：* 內建 44 筆美妝品牌粉底與妝前乳資料庫，依使用者的膚色等級與副色調進行智慧適配，提供遮瑕、校色與防曬指導。
* **[medical_alert.py](file:///l:/Lumiere/Back_Lumiere/dev/app/medical_alert.py)**
  * *說明：* 醫療警示與 Triage（分流系統）。當分析結果中的疑似惡性腫瘤 (`melanoma_suspected`)、可疑皮損等信賴度高於 `0.85` 時，觸發醫療警告標記，**強制清空美妝產品推薦**，並警告使用者尋求皮膚科醫師諮詢。
* **[db.py](file:///l:/Lumiere/Back_Lumiere/dev/app/db.py)**
  * *說明：* 資料庫連線引擎。使用 SQLAlchemy 讀取連線字串，建立資料庫連線池。
* **[data_service.py](file:///l:/Lumiere/Back_Lumiere/dev/app/data_service.py)**
  * *說明：* 分析歷史記錄的 CRUD 服務。存檔時自動為每筆分析生成 `ana_[8碼十六進制]` ID，將結果與完整 JSON 以 `JSONB` 格式寫入 PostgreSQL；並提供讀取 API 查詢。
* **[mediapipe_utils.py](file:///l:/Lumiere/Back_Lumiere/dev/app/mediapipe_utils.py)**
  * *說明：* 人臉特徵點 (Landmarks) 工具。使用 MediaPipe 偵測臉部 478 個特徵點。*注意：其分區物理裁剪功能目前已完全被 BiSeNet 19 分類模型取代，此檔案目前主要作為備用。*
* **[README_INTEGRATION_NOTES.txt](file:///l:/Lumiere/Back_Lumiere/dev/app/README_INTEGRATION_NOTES.txt)**
  * *說明：* 內部整合備忘錄，記錄關於膚色等級、副色調判定以及 API 資料傳遞的注意事項。

#### 3.1.3 `dev/app/models/`
* **[blaze_face_short_range.tflite](file:///l:/Lumiere/Back_Lumiere/dev/app/models/blaze_face_short_range.tflite)**

### 3.2 `data-collection/` - 數據收集與離線工具 (Data Collection & Offline Scripts)

此目錄用於整理和準備模型訓練所需的原始圖片與標註數據，並提供離線測試演算法的腳本。

#### 3.2.1 數據集子目錄 (Dataset Subdirectories)
* **`melasma/`**：黃褐斑（Melasma）影像數據集，包含 images、binary masks 以及劃分好的 train/val/test 檔案列表。
* **`melasma_coco/`**：COCO 格式的黃褐斑數據集，直接自 Roboflow 標註平台下載。
* **`vitiligo/`**：白斑（Vitiligo）影像數據集，結構同上。
* **`vitiligo_coco/`**：COCO 格式的白斑數據集。
* **`port_wine_stain/`**：鮮紅斑痣影像數據集。
* **`makeup_products/`**：整理自 Open Beauty Facts 與 Kaggle 的 concealers (遮瑕) 和 primers (妝前乳) CSV/JSON 對照表。

#### 3.2.2 `data-collection/scripts/` - 離線腳本
* **[face_parsing_bisenet.py](file:///l:/Lumiere/Back_Lumiere/data-collection/scripts/face_parsing_bisenet.py)**
  * *說明：* 離線測試 BiSeNet 對影像的語意分割與視覺化疊加效果。
* **[skin_region_extraction.py](file:///l:/Lumiere/Back_Lumiere/data-collection/scripts/skin_region_extraction.py)**
  * *說明：* 離線測試皮膚區域特徵像素提取。
* **[rgb_estimation.py](file:///l:/Lumiere/Back_Lumiere/data-collection/scripts/rgb_estimation.py)**
  * *說明：* 計算特定圖片中皮膚像素的 RGB 分布並輸出為統計資料 JSON。

### 3.3 `training/` - 機器學習模型訓練與評估 (Model Training & MLOps)

包含完整 SegFormer 模型的訓練、微調、評估管線，以及生產環境所需的模型權重庫。

#### 3.3.1 權重庫 `training/checkpoints/`
* **`BiSeNet/`**
  * `79999_iter.pth`：BiSeNet 19 分類臉部語意分割模型。
  * `bisenet_best.pth`：BiSeNet 14 分類膚色特徵提取模型。
* **`SegFormer/`**
  * `models/`：包含目前生產線啟動優先載入的獨立專家模型 (`melasma/`, `port_wine_stain/`, `vitiligo/`)，內含 `model.safetensors` 與 `deployment.json`。
  * `deprecated/`：存檔之舊版或聯合訓練模型（如四分類聯合模型 `unified/best` 等）。

#### 3.3.2 網路定義與訓練腳本

  * *說明：* 自動微調/重新訓練所有病灶 SegFormer 模型的主管線腳本，能遍歷並記錄訓練狀態至 `experiments.json`。

* **[experiment_report.md](file:///l:/Lumiere/Back_Lumiere/training/experiment_report.md)**
  * *說明：* 自動生成的訓練實驗報告，比較了不同模型在黑斑、皺紋等項目的指標。
* **`training/models/`**

## 4. 開發與維護要點 (Developer Guidelines)

1. **環境配置與依賴**
   * 專案已排除虛擬環境目錄 `venv`。新開發人員應在根目錄下執行 `python -m venv venv` 建立虛擬環境，並以 `pip install -r requirements.txt` 安裝硬體中立的套件依賴。
2. **敏感資訊隔離**
   * 絕不可將包含真實 API Key 的 `.env` 檔案提交至版本控制。請根據 `.env.example` 在本地建立並配置 `.env` 檔案。
3. **測試驅動與驗證**
   * 當修改分析管線或演算法時，請執行 `tests/` 下的自動化單元測試以防引入 regression 錯誤：
     ```bash
     pytest tests/
     ```
4. **模型權重部署**
   * 專案運作高度相依於 `training/checkpoints/` 下的權重。若在生產環境使用 Docker 部署，請確保在 Docker 映像檔建置或容器啟動時正確將模型權重複製或掛載（如 Volume）至容器內對應路徑。
